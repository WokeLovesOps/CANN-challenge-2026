# 点1瓶颈分析

结论：当前最小单点积路径是延迟受限的小任务。优先研究向量指令的掩码/模式设置和短搬运参数开销，不优先改Cube或增加核数。本轮只分析，正式源码未修改。

## 适用范围

仓库代表输入为B=M=N=1、K=32、FP16/NN。历史记录确认过OJ点1为FP16单点积，但具体K未确认，因此本文不将K=32当作已知官方隐藏形状。当前ComputeSingleDot适用于单batch、单输出、FP16、K≤64的合法输入；更大K走其他分支，不能直接套用本次流水数据。

正式源码SHA256：`17f4ea4969d62c6c59e6ec86aa396b7516c40ee124978c627e86ae53fee884ce`，包含已合入的点5Vector尾段优化，不包含未采用的B优先搬运候选。

## 执行路径与工作量

Profiler核名为 `_ZN13batch_max_sum16ComputeSingleDotIDhEEvPhS1_S1_j`，类型vector，Block Dim=1。源码函数位于约143行，host调用位于约4004行。

该输入的数学运算退化为一个长度32的点积：32次乘法、31次加法，不需要Max操作。两个FP16输入各64字节，输出FP32四字节。固定UB容量800字节，包括256字节输入区、512字节转换区、32字节输出区。逻辑字节量不是实际总线事务量，PMU还包括缓存粒度等影响。

顺序为：固定硬件状态设置、参数及地址判断 → GM读入两个输入 → MTE2_V依赖 → 一次Cast转换两个输入 → 一次FP32 Mul → 一次WholeReduceSum → V_MTE3依赖 → 四字节输出。

现有实现已经去掉TPipe/TQue，合并两个输入的Cast，并在输入完整区间紧邻时合并搬运。本轮软件模型中两个输入地址相距512字节，不满足64字节紧邻条件，因此实际执行两条输入搬运。不可假定OJ同样分配地址。

128字节输入和4字节输出远不足以形成持续带宽负载。这些数据支持优先关注短事务、参数加载、同步依赖、指令设置及任务固定延迟，不能准确拆出其中每部分对OJ约2μs的贡献。Host同步的墙钟时间不包含在本轮核计时中，不能据此建议删除Host同步就能获得核内加速。

## 软件模型证据

Ascend910B3模型core0第二次调用，指令时间跨度约0.576μs，不代表真机耗时。相对模型首条指令：

| 阶段 | 相对时间 |
| --- | --- |
| 两条输入搬运 | 约0.230开始，0.384～0.385μs结束 |
| VCONV | 0.387～0.398μs |
| VMUL | 0.400～0.413μs |
| VCADD | 0.424～0.447μs |
| 输出搬运 | 0.448～0.576μs |

指令统计为1条VCONV、1条VMUL、1条VCADD、3条MOV_SRC_TO_DST_ALIGN、2组SET_FLAG/WAIT_FLAG、4条BAR、11条MOVEMASK。另有23条MOV_XD_IMM、14条MOVK以及地址判断分支等控制指令。

首条搬运前约0.230μs包含参数加载、状态设置与地址分支，并非都能优化掉。两个输入搬运在模型时间线中重叠，不能把各自约0.155μs相加。两组WAIT_FLAG用于不同流水的数据依赖，也不能将等待时长相加后视作可节省时间。

## 建议的独立实验

1. 优先研究掩码与向量模式设置。当前Mul使用calCount接口，WholeReduceSum再次设置K掩码；可尝试Mul的显式mask/repeat接口，并让随后求和复用同一K掩码，保留两者之间的数据依赖。远端CANN 9.0的公开basic_api头文件已核实Mul与WholeReduceSum存在isSetMask模板参数。Cast覆盖两个输入，掩码不同，不能直接共用，更不能将11次MOVEMASK全部当成冗余。需比较生成指令及交错真机计时，收益尚未验证。
2. 对满足实际地址和长度对齐约束的输入，研究普通DataCopy替代DataCopyPad的短搬运路径；非对齐输入继续安全回退。目标是减少参数/指令开销，不是增加带宽。当前已经能合并真正紧邻的两个输入，不能重复声称这是新优化，也不能跨分配边界读间隙。输出仅4字节，不可直接扩大为32字节写入。
3. 最后才研究输入地址判断分支的取舍。取消判断可能减少Scalar指令，但会失去紧邻输入的一次搬运收益，必须对正向紧邻、反向紧邻、分离输入分别验证，不按测试编号或输入内容分派。

不优先采用Cube、split-K、多核归约或双缓冲：本任务只有一个很短的点积，没有下一轮搬运可覆盖。也不采用FP16先乘后转FP32：这会改变乘积精度和溢出行为。不能未经依赖分析就删除PipeBarrier或事件等待。

后续优化应覆盖K=32、40、48、56、64、四种属性以及各输入地址关系、图重放、输出保护区；其他合法输入保留通用分派与回退。先交付独立候选，验证后决定采用，远端完整编译仍须≤300秒。
