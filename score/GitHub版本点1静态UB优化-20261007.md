# GitHub版本点1静态UB优化

基线为GitHub提交`882bbc9`。仅修改`src/kernel.asc`中的`ComputeDot32`及其说明注释，其他设备函数和Host入口、分类判断逐字不变，修改范围已静态校验。

## 实现

取消TPipe、三个TBuf和InitBuffer，改为固定地址LocalTensor。FP16实例的输入区为UB字节0至127，FP32转换区为128至383，输出槽为384至415，三个区域互不重叠且按32字节对齐。

显式设置非原子、正常mask模式并重置mask。保留MTE2→Vector、Cast→Mul→WholeReduceSum以及Vector→MTE3的依赖和原始FP32归约顺序。增加MTE3→Scalar完成等待，保证函数返回前输出写回结束，替代原TPipe析构的自动收尾。

## PMU解释

独立PMU三轮与优化前当前GitHub版本三轮相比，Scalar活跃时间均值约0.370降至0.236微秒，AIV计数时间约0.795降至0.678微秒。Vector活跃时间保持0.064242微秒；MTE2约0.236降至0.225微秒，MTE3约0.134降至0.122微秒。结果与减少初始化、控制和收尾开销的方向一致，但不能将某个PMU计数逐项等同源码函数耗时。
